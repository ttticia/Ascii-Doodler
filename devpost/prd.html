Product definition / 02

Doodle to ASCII

A simple doodle editor for younger people to make handmade ASCII art for texts or digital journals.

Built from approved scope / one drawing-to-download journey

The core journey

From first mark to text file

Editor: dismiss welcome → click pen → draw → submit. Blank submit stays here with an error. Otherwise: generating → one # image beside the message → download .txt → confirmation.

Each stage has a defined screen, action, and visible result.

Behavior and acceptance checks

Screen by screen

One PoC flow
01 / Welcome and editor

On first entry, the message appears centered over the canvas:

“Welcome to ASCII doodler! Start drawing in this editor, and when you are done, click submit to generate your image.”

The drawing space is square and responsive to fit phone and desktop browser viewports. The pen and eraser icons sit at the top of the page, outside the drawing space; the Submit button sits at the bottom, also outside it. The user must dismiss the welcome message before drawing. Afterward neither tool is active. The user clicks the pen icon to begin, or clicks the eraser icon to erase. The pen draws black at 30% of a grid cell's width; the eraser is 90% of a cell's width. The active button is white and the inactive button is light grey.

Checkable criteria

  • The square drawing space fits phone and desktop browser viewports; tool icons remain above it and Submit remains below it, all outside the drawing space.
  • The welcome message is centered over the canvas and blocks drawing until dismissed.
  • The canvas accepts pen marks only after the user activates the pen.
  • Clicking either icon activates that tool; the selected button is white and the other is light grey.
  • The pen width is 30% of a grid cell; the eraser width is 90%.
02 / Submit and generate

Submitting an empty canvas shows “canvas cannot be blank” in a pop-up and keeps the user on the editor. Submitting a nonblank canvas changes the screen to a loading page displaying “Generating art :)”. Once ready, exactly one result appears. A grid cell becomes `#` only if pen-mark coverage exceeds 15%; the result uses no other visible art character, preserves the doodle's basic shape, and has no more than 50 characters per line.

Checkable criteria

  • A blank submission shows the exact error text and does not open the loading or result page.
  • A nonblank submission shows the loading message before the result.
  • The finished output uses only `#`, preserves the doodle's basic shape, is at most 50 characters wide per line, and marks a cell only when pen coverage exceeds 15%.
  • If generation fails, the app returns to the editor, preserves the doodle, and shows “could not generate art. please try again”.
03 / Result and download

The result and message box sit in the middle of the page, with the message box to the left of the ASCII image. The message reads “Your ASCII doodle has been generated.” A Download button appears below it.

Clicking Download initiates the `.txt` download, then the app shows “image downloaded”. The text file contains the generated ASCII image. If the app cannot prepare or initiate the download, it shows “download failed. please try again”. A local browser page cannot reliably detect if the browser later blocks or cancels the download.

Checkable criteria

  • The generated art is to the right of the exact result message, with Download below the message box.
  • Clicking Download starts a `.txt` download containing the art and displays “image downloaded”.
  • Clicking Download initiates a `.txt` download containing the art and displays “image downloaded”; this confirms initiation, not that the browser saved it.
  • If the app detects an error preparing or initiating the file, it displays “download failed. please try again”. Later browser cancellation or blocking may not be detectable.
States, scope, and remaining questions

In this proof of concept

  • Welcome overlay, 30%-cell-width black pen, 90%-cell-width eraser, one `#` result with a 15% coverage threshold and 50-character line limit, and `.txt` download.
  • Blank-canvas error, loading message, and download confirmation.
  • A one-minute demo of drawing, generating, and downloading.

Deferred

  • Image import and JPG/PNG export.
  • Shapes, fill, other colors, and adjustable tool sizes.
  • Multiple render levels and clipboard copy.

Product direction

The interface stays black and white, simple, homemade, and reminiscent of early drawing games. The shared art sample guides the output only; the app is not modeled on its source website. The POC uses `#` only and does not reproduce the sample character-for-character.

Generation failure

If generating art fails, return the user to the editor with their doodle intact and show “could not generate art. please try again”.
